# The platform's own training code, as a library: the teacher, the encoding, behaviour cloning
# and the export. It pulls torch, numpy and onnx. It lives in the Ants repository, beside the rules it
# trains against, so pip clones that and builds the `baselines/` subdirectory. Pin a commit when you
# want your run to reproduce:
#   tb-baselines @ git+https://github.com/Tiny-Brains/ants@<sha>#subdirectory=baselines
# `train.py` needs a tb_baselines newer than ants' main, and THIS IS NOT ONLY THE `--memory` PATH:
# it passes `export --repro` on every run, so plain `python train.py` fails at the export step with
# `unrecognized arguments: --repro` until ants' main carries it. The memory flags (`collect
# --remember`, `bc --memory`) are needed only by `train.py --memory`. Until ants' main has both,
# install from a checkout that does: `pip install -e <ants checkout>/baselines`.
tb-baselines @ git+https://github.com/Tiny-Brains/ants#subdirectory=baselines
